# gov-contracts-cd119
Open source government contract graphical exploration


Main file is the H118 DoD git.qgz which is opened in QGIS. 

Start with the DoD_Lands_in_Congressional_Districts, Committee Layers, Agency Layers, and OpenStreetMap displayed. Within the Committee Layers group the Armed Services committee should be selected which shows a cross hatch on the graph for every congressional district where their representative is a member of the House Armed Services Committee. Within the Agency Layers group the Department of Defense layer should be selected and this shows a map colored by total federal obligations during the 118th Congress in millions of USD, I did go into the legend and mark when it hit billions so if for example it says 1.3B then that is $1.3B but if it is just labled as 260 for example then that figure is in millions, i.e. $260M. In order to see different combinations, select a different agency or committee and unselect the original one, you should only have one agency layer selected and one committee layer selected at once.

The DoD_Lands_in_Congresional_District files are the data and styling for outlining military installations. The USA_Department_Of_Defense_Lands folder has geography and labels for what each specific DoD installation is.

The all_cd118_and_committees.gpkg file outlines the congressional districts from the 118th Congress which spanned January 3, 2023 to January 3, 2025. This file contains data on the name and party for the representative for that district and what committees each representative was part of. This file feeds the "all_cd118" layer and the "Committees" group of layers. If you check to visualize the "all_cd118" layer it will show a map of each district colored by party and if click "Show Map Tips" in QGIS which is the icon with a yellow call out bubble from a green dot then when you hover over each district it will display the name of the representative, which district they represent, and their political party affiliation. 

The cd_summary.csv file contains a congressional district level summary of government contracts actioned during the 118th Congress. The file has one row per district and then for each district it has the total federal obligation from the 118th Congress, the federal awarding agency with the highest obligation, the vendor who received the most federal obligations, the number of unique awards, and more summary statistics. The cd_contracts_by_agency_pivoted.csv file contains similar summary statistics broken down by awarding agency. This table is pivoted so that each row is a congressional district and then the columns show total obligation per awarding agency, largest recipient per awarding agency, and a couple other summary statistics. 

The map_ready_addresses.csv file contains the address for every recipient of a federal action obligation during the 118th Congress. If you make this layer visible it will show a pin for every address so you can see higher density spots but it does not have any contract values attached to it so all you can visualize is unique addresses, no sense of number of contracts per address or total obligation per address.
